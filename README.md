# Linux Permissions & Access Control Lab

## 📖 Introduction
This repository documents a hands-on cybersecurity task focused on **Linux File Permissions and Access Controls**. Completed as part of the [TuteDude Cybersecurity Training](https://tryhackme.com/jr/tutedude-cybersec), this project demonstrates how Linux multi-user operating systems secure system files and how authorized users can modify permissions to manage resource accessibility.

## 🎯 Objective
The primary objective is to explore the Linux permission model (User, Group, and Others). The goal was to navigate a target Linux machine via SSH, inspect directory permissions using `ls -l`, and modify access controls via `chmod` to successfully read restricted file contents at `/home/student/practice/restricted_file.txt`.

## 🛠️ Steps Performed
1. Connected to the target machine via SSH from the [TryHackMe Room](https://tryhackme.com/jr/tutedude-cybersec).
2. Inspected existing file permissions using `ls -l`.
3. Used the `chmod` command to adjust file access rights.
4. Read the restricted file contents and captured the required flags.
